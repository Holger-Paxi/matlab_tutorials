# Shortcuts/keystrokes for *MATLAB Live Scripts* and *MATLAB Scripts*

## Run code

| Action                       | Shortcut               |
| ---------------------------- | ---------------------- |
| Run current section          | `Ctrl + Enter`         |
| Run section and move to next | `Ctrl + Shift + Enter` |
| Run entire Live Script       | `F5`                   |
| Run selected code            | `F9`                   |

## Section

| Action                | Shortcut                              |
| --------------------- | ------------------------------------- |
| New section           | Type `%%` or `Ctrl + Alt + Enter`       |
| Run current section   | `Ctrl + Enter`                        |
| Move between sections | `Ctrl + Up/Down` (depends on version) |

## Editing

| Action                         | Shortcut                                    |
| ------------------------------ | ------------------------------------------- |
| New line below current line    | `Enter`                                     |
| Toggle Code-Text               | `Alt + Enter`                               |
| Insert line above              | `Ctrl + Shift + Enter` (depends on version) |
| Comment selected lines         | `Ctrl + R`                                  |
| Uncomment selected lines       | `Ctrl + Shift + R`                          |
| Undo                           | `Ctrl + Z`                                  |
| Redo                           | `Ctrl + Y`                                  |
